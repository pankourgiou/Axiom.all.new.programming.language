Language reference
FeatureSyntax
Valuesnumbers 3.14 2e-3, lists [1,2,3], text "hi", true/false, functions. Constants: pi π e tau phi inf
Operators+ - * / ^ % (^ is right-assoc; % is true mod), n!, comparisons == != < > <= >= (chainable: 0 < x < 1), and or not. Also × · ÷ ≤ ≥ ≠
Implicit multiplication2x, 3(x+1), 2pi, (x+1)(x-1), -2x^2
VectorsOperators and math functions broadcast: [1,2,3]*2, [1,2]+[10,20], sin([0,pi]). Indexing is 1-based: a[1], a[-1] (last)
Ranges & comprehensions1..10 (inclusive, counts down if reversed) · [k^2 for k in 1..10 if k%2==0]
Definex = 5 · f(x,y) = x^2 + y · g = x -> x+1 · (a,b) -> a*b · += -= *= /=
Conditionalsif x > 0 then 1 else -1 · if c { ... } else { ... } (an expression: has a value)
Blocks & loops{ a = 1; a + 1 } (value = last line) · for i in 1..5 { ... } · while cond { ... } · return v
OutputBare expressions print their value (→). print(a, b) prints anything. plot(f, a, b), plot([f,g], a, b), plot(xs, ys)
Calculus & solvingd(f, x) derivative at x · d(f) derivative function · integral(f, a, b) · root(f, a, b) (bisection) · newton(f, x0)
Seriessum(list), sum(k -> 1/k^2, 1, 100), prod(...), cumsum(list)
Mathsin cos tan asin acos atan atan2 sinh cosh tanh sqrt cbrt abs exp ln log(x[,base]) floor ceil round(x[,digits]) sign deg rad min max
Lists & numberslen range(a,b[,step]) linspace(a,b,n) map(f,L) filter(f,L) fold(f,init,L) sort reverse mean dot norm concat gcd lcm choose(n,k) isprime primes(n) factors(n) rand() randint(a,b)
FilesPrograms are plain-text .axiom files. Open / Save (Ctrl+O / Ctrl+S), or drag a .axiom file onto the page. Chrome/Edge save in place; other browsers download the file.
Comments# to end of line · Statements are separated by newlines or ;

Experimental: no complex numbers or symbolic algebra; assignments inside a function are local; programs stop after 6 million steps.
